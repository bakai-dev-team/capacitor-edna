# Проверка плагина edna

Сначала соберите JS-пакет в родительском каталоге:

```sh
cd ..
npm install
npm run build
```

Затем из папки плагина:

```sh
cd example-app
npm install
npm run build
npx cap sync
npx cap open android
# либо
npx cap open ios
```

В Android Studio/Xcode соберите и запустите приложение. На форме укажите
параметры тестового стенда и тестовый userId, затем нажмите
«Открыть чат». token/scheme заполняйте только для кастомной авторизации. Убедитесь, что сообщение получил оператор и ответ появился в чате.
Для смены клиента выполните «Выйти из чата», для смены стенда полностью
перезапустите приложение. Поля не сохраняются и токен не выводится в журнал.

Пример открывает настоящий интерфейс SDK на Android/iOS. В браузере он только
показывает форму. Настройки и credentials не включены: их предоставляет ваш стенд.
Форма для ручных тестовых credentials не предназначена для банковского production UI.

Каналы Firebase/APNs и автоматическое открытие из push настраиваются в приложении
по [инструкции](../docs/push.md). Банковский PIN/вход этот пример не имитирует.
